# Temperature-Converter
### A simple rust CLI program to convert temperatures
---
## Build
```bash
git clone ...
```
```bash
cd Temp-Converter
```
```bash
cargo run
```
---
## Input
The only input format which is supported is:
```bash
"X[T1] to [T2]"
```
or
```bash
"X[T1]to[T2]"
```

where T1 and T2 are either one of {"C","F","K"} and X is a number.
